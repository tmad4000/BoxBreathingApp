# Timing options — future ideas

The current release remains four equal four-second phases with a four-round
checkpoint. Settings offers sound/haptics and support information, not a large
configuration panel.

Standard guidance describes equal four-count phases and a few rounds:
- https://health.clevelandclinic.org/box-breathing-benefits (three to four rounds)
- https://www.heart.org/en/news/2023/07/07/its-not-just-inspiration-careful-breathing-can-help-your-health (three to five cycles for beginners)

An adjustable equal-phase duration could be useful later for comfort. If added,
it should preserve equal sides, use a single clearly labeled control, show the
resulting session duration, apply changes only to a new session, and retain a
clear default. It should be user chosen rather than claiming longer is better.

Automatic faster-to-slower pacing was not established as a standard box-breathing
protocol by the reviewed sources. Keep it out of the initial release. Revisit only
with a defined comfortable protocol, evidence, clear labeling and explicit opt-in.
No clinical benefit claims should be inferred from a progressively slower timer.
